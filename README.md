# Highlighter-Obsidian

<small>Highlighter is a plugin that mimics Obsidian's UI and adds core functionality to the PDF reader, such as highlighting, freehand ink drawing, text boxes, and inline annotations. Designed to work with any cloud saving method, including OGD Sync.</small>

---

Annotations are rendered on top of the PDF rather than inline, making performance faster with no page refreshing.
