# Highlighter-Obsidian
<small> Highlighter is a plugin that mimics Obsidian's UI and adds core functionality to the PDF reader. Such as highlighting, freehand ink drawing, text boxes and inline annotations. Designed to work with any cloud saving methods, including OGD Sync.<small>
